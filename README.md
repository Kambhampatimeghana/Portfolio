## 🌟 About the Project

Welcome to my personal portfolio website! This portfolio showcases my skills, educational background, projects, achievements, and coding profiles as a Computer Science undergraduate.

It is designed with a modern dark theme, glassmorphism UI, smooth scrolling, and scroll-reveal animations to provide an engaging user experience.

## ✨ Features

- 🎨 Modern dark-themed UI with glassmorphism effects
- 👩‍💻 Personal introduction and About Me section
- 🛠️ Technical skills and technologies
- 🎓 Education timeline
- 🚀 Projects showcase
- 🏆 Achievements section
- 💡 Coding profiles
- 📬 Contact section
- ✨ Smooth scrolling navigation
- 🎭 Scroll-reveal animations
- 📱 Responsive design

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Kambhampatimeghana/Porfolio.git
```

### 2. Navigate to the Project

```bash
cd Porfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

### 5. Build for Production

```bash
npm run build
```

The production-ready files will be generated in the `dist` directory.
